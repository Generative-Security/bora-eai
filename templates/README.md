# Templates

Working templates for running BORA-EAI. Copy them into your own tools; the CSV files open in any spreadsheet.

| Template | Use |
|---|---|
| [use-case-register.csv](use-case-register.csv) | One row per AI use case (Layer 1 onward). Includes two example rows to delete |
| [scenario-register.csv](scenario-register.csv) | One row per applicable scenario per use case (Layer 5 onward). Example rows from the worked example |
| [use-case-assessment.md](use-case-assessment.md) | Full assessment through all nine layers |
| [fast-lane-patterns.md](fast-lane-patterns.md) | Pre-approved patterns for the fast lane, with examples |
| [sovereignty-profile.md](sovereignty-profile.md) | The six-axis sovereignty profile (Layer 3) |
| [board-summary.md](board-summary.md) | One-page summary for a board or executive committee |

Example rows are illustrative and should be deleted before use. See the [worked example](../docs/examples/worked-example-customer-service-chatbot.md) for all templates in use.
